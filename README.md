This is a program that lets you choose a hypothesis test to perform. You can run Main.java and input the necessary values for each step along the way. The steps and checking of conditions will get printed (output) to the console, and the most important values (e.g. test statistic, p value, etc.) will get printed to an output file with the name of the test (e.g. homogeneity.out, independence.out, oneMeanTTest.out, twoMeanTTest.out, twoPropZTest.out, etc.). Have fun hypothesis testing!
